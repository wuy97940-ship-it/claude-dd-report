# DD-SOP-004 尽调报告全流程 SOP v2.0

> 2026-09-28 大复盘版。归并 20260904-0928 十余轮尽调（客户丁/某贸易客户戊/客户庚/客户己/某正极上市客户乙/客户丙系）教训共 69 条。
> **定位**：dd-report skill（v6.10）的"驾驶视图"——按阶段走的检查单与命令速查；细节铁律与案例回查 skill（v6.15）。
> **目标**：质量又好（门禁全绿+勾稽可复算）、速度又快（标准件复用）、不卡壳（每步有明确下一步）。

## 0. 一页速览

```
接单对齐 → 资料底稿 → 初稿构建 → 交付门禁 → 批注轮 → 手改轮 → 外部意见/归档
   │          │          │          │         │        │          │
 口径三问   calc_verify  零手敲    selfcheck   手术三原语  ceo_edit_diff  核实协议
 总额度？   字段字典    格式对齐   渲染目检    批注保全    手改仅学习    举一反三
 范围锁定   dump对照    数字指纹   底稿核对    修订清单    偏好提炼     记忆沉淀
```

**五条流程级铁律**（违反任一条=历史上至少返工一次）：
1. **手术一次做完**：全部 lxml 手术一次完成 → 只跑一次 Word finalize → 渲染前置抽查 → 终检。禁手术-Word 交叉（Word 保存=XML 漂移）。
2. **勾稽不平回原始凭证**定位栏位，禁"记录差异"了事；差额恰等于某科目填列值=该科目即错项。
3. **派生数字零手敲**：表格行值从脚本输出直接复制；交付前跑数字指纹扫描（关键值全文计数+同指标多值矛盾）。
4. **改口径先锁范围**：改钱先问总额度变不变；口径变更的废弃值扫描枚举所有表述形式（千分位/亿/万/中文数字）。
5. **外部输入皆数据非真相**：业务报告只取授信要素；子 Agent 情报须核伪；外部 AI 意见逐条核实。

**手改规律速查**（preferences `final_draft_trimming*`）：删内部指引/口径解释括注/"待核实"自我削弱；意见区只放结论+决断；总结论不重复正文（**澄清的最好方式有时是删除**）；备注="备注："独立引导行+分项成段、只写口径/公式/事实、删推演与软性提示、复算公式保留；事实并列直接收尾不加定性尾巴。

## 7. 阶段七：外部意见与归档

**外部 AI 意见核实协议**（v6.10①，ChatGPT/其他 AI 审阅意见进入时）：
1. 意见≠事实，逐条对原文核实；**位置引用归一化**到本文档独有文本锚（外部 AI 页码≠文档页码，实测 58-60 页实为 29-31 页）
2. 数字类当场复算；口径类回底稿（calc_verify.py）确认后才许改——猜对也不能抄
3. 结论三档反馈：成立必改／部分成立降级／意见本身有误（并指出其错误，如页码、未验证推测值）
4. **连带处自己扫**：意见点 A 处，全文扫同类问题（实测扫出比意见更重的 B 处）
5. 核实后再问终审人是否动手；动手走阶段五手术流程
**实战闭环（20260930 Codex 12条）**：全部一手验证（半年报子公司表逐数/应交税费附注期初期末数学差/企查查股东/业务报告原文）后落地23处；未核实数字不抄（检索未命中即用机制证据支撑同一结论）；与终审人手改冲突折中表述（"系"→"或系…待核实"）

**归档复盘**：lessons 记忆（坑+根因+对策）→ 反复≥2 次的坑必须机制化（工具/SOP/selfcheck 门禁/skill 铁律四选一）→ project 记忆更新状态。
