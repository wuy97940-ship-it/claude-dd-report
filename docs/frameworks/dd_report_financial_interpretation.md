## 一、导航结构（让小节出现在 Word 导航窗格）

**规则**：节/条不用"标题"样式，而是给**普通段落设 outlineLvl**（保持正文格式不变，但导航窗格/大纲可展开；两端对齐等正文格式保留）。cpahelp 插件即此原理，我用 python-docx 复刻：

| 层级 | 内容 | outlineLvl | 实现 |
|------|------|-----------|------|
| 一级 | 章（一、二、三…）/ 概述(尽调报告意见/释义) | 0 或"标题1"样式 | 用 Heading 1 |
| 二级 | 节（（一）（二）（三）…） | **1** | Normal 段 + `w:outlineLvl val=1` |
| 三级 | 条（1、2、3、…如"1、资产负债表"） | **2** | Normal 段 + `w:outlineLvl val=2` |

```python
from docx.oxml.ns import qn
def set_outline_level(p, lvl):        # lvl: 0=一级 1=二级 2=三级
    pPr = p._element.get_or_add_pPr()
    ol = pPr.find(qn('w:outlineLvl'))
    if ol is None:
        ol = pPr.makeelement(qn('w:outlineLvl'), {}); pPr.append(ol)
    ol.set(qn('w:val'), str(lvl))
# 例：把"1、资产负债表"设为三级标题(出现在导航)
# set_outline_level(该段, 2)
```

**注意**：设 outlineLvl 不改变字体/排版（仍宋体+TNR、两端对齐），只是导航可见。要在插入/生成正文段时一并设好。

## 二、解读段写法（v2 · 随主体风险画像自适应）

**三段基础结构**（放"XX主要资产负债科目如下表所示："之前），分段/详略/加粗**跟随风险画像**：

**低负债+盈利**（如客户乙之子公司乙152%负债率）：
1. 总体：总资产/净资产/资产负债率 + 较上年末变动。
   > 截至2026年3月31日，XX总资产85.23亿元、净资产40.65亿元、资产负债率52.32%；较2025年末（…），资产总额增长11.84%，资产负债率上升2.80个百分点。
2. 构成：资产/负债/权益 top-N（各留前3大/前1大）+ 固定资产产能占比+一处跨引用。
3. 变动大项目：两期变动比较大的报表项目如下：①…②…（项目+±%+一句业务原因）。

**高负债+累计亏损**（如客户乙之子公司乙278.5%负债率）：
- 总体（同上）。
- 资产构成+固定资产产能（**负债端细节省略**）。
- **权益单独段**强调风险：所有者权益X亿元，以实收资本、资本公积为主，未分配利润-X亿元、仍为累计亏损。
- （口径微调：风险落在权益/现金流时，次要负债构成删减。）

**利润段**：数字（营收/净利/毛利率+变化）必写；**原因只在它是亮点（扭亏/改善）时写**（"储能爆发+碳酸锂涨价→量价齐升"），重复/次要则只留数字。

**现金流段**：数字一段（经营/投资/筹资净额+现金净增减+期末余额）+ **独立结论段**"总体看，<关键风险>"。

**加粗唯一合法场合**：**关键风险结论句**加粗（如"总体看，公司经营现金流尚未转正、较大程度依赖融资支撑备货扩张"）。数据/其他叙述段一律不加粗；只有"（三）XX""（一）技术专利"这类**标题**加粗。

**铁律**：构成只列top-N；删"其余为…"铺陈；删冗余括号（净资产（所有者权益）→净资产）；跨引用只留一处；变动原因业务化（存货=备货/应收=正相关营收/预付=备货/应付=采购/一年内到期=长期借款转入/货币资金降=备货偿债占用/长期借款降=转一年内）；正文段**两端对齐(JUSTIFY)**+首行缩进2字符+宋体+TNR；标题"XX变动比较大的报表项目如下："。

## 三、财务知识速查（写解读/分析/尽调用）

- **三表勾稽**：资产=负债+权益；期末未分配利润=期初+本期净利-分配；期末货币资金=期初+经营+投资+筹资+汇率；经营现金流≈净利+折旧摊销减值±营运资本变动（应收增-、存货增-、应付增+）。
- **关键比率**：毛利率、净利率、营业利润率、ROE(杜邦=净利率×周转×权益乘数)、ROA；应收周转天数=应收/营收×360、存货周转=存货/营业成本×360；资产负债率、流动比率、速动比率；净现比=经营现金流/净利、销售收现率=销售商品收到现金/营收（低=回款弱）。
- **舞弊/盈余质量信号**：营收增但经营现金流为负/净现比<0；应收增速远超营收；销售收现率低；存货高企+跌价；经营现金流连续为负依赖筹资；**非标审计意见**；大额商誉/资产减值；毛利率异常高于同行；非经常损益+其他收益撑利润；存贷双高（资金占用/虚增）。
- **CAS要点**：收入CAS14(控制权转移/五步法/总额vs净额)、应收减值CAS22(ECL三阶段)、存货CAS1(成本与可变现净值孰低)、固定资产/无形资产(折旧摊销/减值/资本化vs费用化)、政府补助CAS16、现金流量表直接法+间接法。

## 四、插解读段代码骨架（python-docx，含两端对齐+不加粗）

```python
from docx.enum.text import WD_ALIGN_PARAGRAPH
from docx.oxml.ns import qn
def insert_analysis_before(intro_para, text):
    p = intro_para.insert_paragraph_before()
    pf = p.paragraph_format
    pf.alignment = WD_ALIGN_PARAGRAPH.JUSTIFY           # 铁律：两端对齐
    pf.first_line_indent = intro_para.paragraph_format.first_line_indent
    pf.line_spacing = intro_para.paragraph_format.line_spacing
    run = p.add_run(text); run.bold = False             # 叙述段不加粗
    rpr = run._element.get_or_add_rPr(); rf = rpr.makeelement(qn('w:rFonts'), {})
    rf.set(qn('w:ascii'),'Times New Roman'); rf.set(qn('w:hAnsi'),'Times New Roman'); rf.set(qn('w:eastAsia'),'宋体')
    rpr.insert(0, rf)
    return p
# 若该段需在导航二级展现: set_outline_level(p, 1)
```

## 五、尽调报告整体章节框架（终审人定稿版 · 2026-08-23 某正极材料上市客户乙）

> 复刻版：新能源材料贸易（碳酸锂/磷酸铁锂正极等）授信尽调报告的章节骨架，拿来即用。编号/导航按前述标题1 / outlineLvl1 / outlineLvl2 三层。

1. **尽调报告意见**：项目需求 / 基本面 / 重点风险提示 / 总体评估与风控措施（一段式末尾，建议要求母公司担保+补充征信+报表原件复核+持续跟踪价格）。
2. **释义**：简称 ↔ 全称对照表（主体/我司/原材料/可比公司/客户）。
3. **一、项目概况**：（一）项目需求（授信要素：额度/账期）（二）额度测算依据及账期说明【1、额度测算依据 2、账期说明】（三）历史合作情况（四）近半年走访记录（五）与XX厂合作复盘。
4. **二、行业概况**：（一）行业背景【1、产业链和市场需求 2、上游原材料价格波动 3、行业竞争格局(产能/产量/出货量集中度) 4、行业供需预测】（二）行业门槛【1、技术与工艺门槛 2、客户认证门槛 3、资金门槛】。
5. **三、公司基本情况**：（一）XX基本情况（信用代码/法代/注册资本/参保）（二）另一主体基本情况（三）母公司总体介绍（四）**实际控制人简介**（五）产能概况（各基地产能表）。
6. **四、新增授信主体的财务状况**：（一）提示（报表未经审计）（二）XX财务报表【1、资产负债表 2、利润表 3、现金流量表】→ 各表前配解读段（见本模板二）（三）另一主体财务报表（同）（四）财务综合评价。
7. **五、同行业可比公司分析**：（一）同行可比公司选取（二）对比总览（三）**常规财务指标对比**【1、2026年一季报 2、2025年年报】+2段指标描述（四）客户集中度对比分析（五）经营现金流分析（七）XX中报披露参考（注意编号可跳跃）。
8. **六、信用与处罚情况**：（一）信用情况概述（企查查扫描）（二）银行融资情况（待征信核实）。
9. **七、总结**：（一）公司亮点（二）主要风险（三）授信建议。

### 常规财务指标对比格式（（三））
- **两张表**：2026年一季报 + 2025年年报，列 = 公司 | 营业收入 | 总资产 | 归母净资产 | 归母净利润 | 毛利率 | 净利率 | 资产负债率 | 应收周转(天) | 存货周转(天)；行 = 可比公司A/B/C/D（同行业头部，使用时替换为实际选取的可比对象）。
- **两段描述**（表后）：①事实段（不加粗）：行业盈利改善（2025仅龙头盈利→2026Q1全盈，量价齐升）+毛利率回升（弹性最大者）+资产负债率普遍偏高（谁最高/最低）+营运（谁的应收周转最长、下游占款重）；②**总体看风险结论段**（关键句标粗）：授信主体母公司 的盈利弹性 vs 偿债/营运相对偏弱，结合授信业务重点考察回款质量与现金流改善，审慎核定额度账期。
