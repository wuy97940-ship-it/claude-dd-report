# 尽调报告·财务报表机制（识别→取数→列示→分析→勾稽→异常备注/内控缺陷提示）

> 2026-08-23 定调。核心原则：**报表原封不动识别+粘贴，不做数据修正；发现问题或勾稽不一致，在报告"说明"，并提示该企业财务内控/报表质量可能存在缺陷**（这本身就是放账尽调的重要发现）。

## 一、识别取数（原封不动）
- 报表来源：
  ①**上市公司**→公开披露 + 财务数据接口（资产负债表/利润表/现金流量表/财务指标）+ 同花顺/年报附注；
  ②**非上市**→企业提供的**财务报表扫描件**，用 `qcc-document` 解析 / EasyOCR 识别。
- **原则：扫描件识别出多少就是多少，原封不动入报告**；不因"看起来不对"而改数。
- OCR 值必须备注：「以上为报表扫描件 OCR 识别结果，个别数字可能误差，正式授信前须以报表原件复核」。

## 二、列示
- 数据先进 `content.json`（数据层），构建器零硬编码，格式母版克隆。
- 三表标准列（终审人审阅习惯）：
  - 资产负债表：项目 | 最新期末 | **占比** | 上期末 | 较上期末变动 | 再上期
  - 利润表 / 现金流量表：项目 | 本期 | 上年度 | 变动比例 | 再上期
  - 资产负债表可加**毛利额**行（营业收入−营业成本）用于看毛利率。

## 三、勾稽校验（必须过，不过=数据异常，须备注）
**资产负债表**：
- **资产总计 ＝ 负债合计 ＋ 所有者权益合计**（平衡）
- 流动资产合计 ＋ 非流动资产合计 ＝ 资产总计
- 流动负债合计 ＋ 非流动负债合计 ＝ 负债合计
**利润表**：
- **毛利额 ＝ 营业收入 − 营业成本**
- 营业利润 → 利润总额 → 净利润 逐级勾稽
- **净利润 ＝ 利润总额 − 所得税费用**
**现金流量表**：
- 经营 ＋ 投资 ＋ 筹资活动净额 ＝ 现金及现金等价物净增加额
- 期初余额 ＋ 净增加额 ＝ 期末余额

## 四、分析列（占比/比率）
- 资产项占比＝该项÷资产总计；负债项占比＝该项÷负债合计；权益项占比＝该项÷所有者权益合计
- 利润表各项占比÷营业收入 → 直观读**毛利率**(毛利额/收入)、**净利率**(净利润/收入)
- 周转天数与账期匹配分析；财务比率（偿债/盈利/营运）放财务状况内编号小节

## 五、异常/不一致 → 备注说明 + 内控/造假信号提示（放账重点）
勾稽不一致 或 出现以下"财务内控/报表质量缺陷"信号 → 报告**备注说明**，并提示（核实后）：
- 勾稽不平衡（资产≠负债+权益；净利≠利润总额−所得税）
- 收入与现金流背离（营收增长但经营现金流弱于净利润）→ 应收占款/回款质量
- 应收账款/存货异常扩张（增速远高于营收）
- 毛利率/费用率异常波动、大额一次性项目（大额所得税抵减、大额计提/减值）
- 商誉高、存贷双高、股权质押过高、应收周转与账期严重不匹配
- 数据交叉验证：审计意见、监管问询函、年报附注；**仅供研究不构成投资建议**
