## ★ 尽调顶层：两大核心目的 + 资信风险视角 + 方法论（先读）

> 这是尽调报告的"为什么+怎么看"，落在任何写作标准之前。出处：终审人 2026-08-23 定调 + 2025-12-27 授信委托方高管课件。

### 1. 两大核心目的
1. **了解清楚这家公司的一切，包括它所在行业** —— 公司全画像 + 行业全景。
2. **在我方业务需求下，看与这家公司合作存在什么风险点、要关注哪些重点风险、思考风控措施** —— 一切落到"能不能安全合作"。
- **合格检验**：读完后①了解公司与行业；②站在业务合作视角，风险点/重点风险/风控措施清晰可执行。风险要**场景化**（业务模式不同，风险截然不同）。

### 2. 资信风险视角（放账是主业 → 首要=资信风险）
- 我司主营 = **放账期/垫资 = 借钱给对方**（如应收账款授信），本质是借出资金、靠回款回收。故**首要风险 = 资信风险**。
- 多维度看"**实力**（还得起吗）+ **资信**（愿意还吗/会不会变坏）"：
  - **实力**：经营收入/利润/现金流、资产质量（应收账龄/存货/货币资金）、偿债（流动/速动比率、有息负债、现金流覆盖）、行业地位（龙头/市占率、客户结构、技术壁垒）、背景增信（上市公司母公司/实控人/可要求担保）。
  - **资信**：历史履约回款、司法信用（诉讼/被执行/失信/限高/股权冻结/终本/破产重整/行政处罚）、纳税信用评级、控制权（股权质押/冻结/频繁变更）、负面（舆情/商誉减值/关联占用）。
- 数据落地：企查查 MCP（实力=财务三表/产品/基本信息；资信=35项风险扫描+失信+被执行+冻结+纳税信用+关联风险）+ 同花顺/公开披露 + 征信报告。

### 3. 行业定位（挑客商）
行业头部（规模大/资金厚/掌控话语权）/ **行业中段（有一定规模但扩产或上下游资金不匹配→紧张，正是目标客商，必须配风险识别能力）** / 底部（规模小/资金短缺）。

### 4. 尽调方法论（课件）
- **调研渠道**：政府、行业协会、头部行业研究院、行业头部企业。
- **尽调对象 = 查公司 ≈ 查人背调，六维对偶**：
  公司①股东背景 ②上下游/竞对 ③运营情况 ④硬件基础 ⑤文化及管理风格 ⑥三张报表
  ↔ 人①家庭背景 ②朋友圈 ③经济条件 ④外貌 ⑤性格 ⑥体检报告。
- **尽调六法**：访谈公司业务/财务/仓库员工；访谈股东/管理层；与外部机构(银行等)沟通；与行业调研、同行业可比对比；上下游、同行口碑；报表查验及分析。
- **金句**："比你更了解自己的人，是借你钱的人"（银行/上下游/同行等"被摸过底"的渠道最可信）。

### 5. 尽调非一次性：动态监控与预警
定期关注财务经营 + 履约 + 行业跟踪；每周按三项资产表盯逾期/未交货客商；网络每个工作日跟资信/舆情；上市看披露/非上市收季半年年报；**建立预警机制及时调整策略/模式、必要时退出、重大提级事业部**。

### 6. 监管合规（为什么必须做）
国资委令第46号（2025-11-28公布，2026-01-01施行）：监管从"提倡"到"追责"；未履行/未正确履行尽调职责致国资损失 → 责任人经济/职务/资格三罚；集团管控管"做什么+怎么做"（合同/价格/付款/应收）；尽调是识别规避虚假贸易的关键防线与"正确履职"证明。

### 7. 财务报表机制（实力面/财务章节执行）— 必读
写财报相关章节前必读 `docs\frameworks\dd_report_financial_mechanism.md`：
- **报表原封不动识别+粘贴，不做数据修正**；OCR 值备注"待原件复核"。
- **勾稽校验（必须过）**：资产总计=负债合计+所有者权益合计；毛利额=营业收入−营业成本；净利润=利润总额−所得税费用；现金净额=经营+投资+筹资。
- 占比/毛利率/净利率口径；**异常（勾稽不平、收入与现金流背离、应收/存货异常扩张、大额一次性项目、商誉/存贷双高/质押过高）→ 备注说明 + 提示该企业财务内控/报表质量缺陷**（放账重点发现）。
- 财务知识（企业会计准则）：`kylin985ti/china-accounting-skills` · `Honeysucklekle/financial-statement-entry-skill` · `quantskills/skill-audit-opinion-scanner` · `akshare-fraud-pattern`。

> 出处：`memory/feedback/feedback_dd_two_core_purposes_20260823.md` · `feedback_credit_extension_credit_risk_lens_20260823.md` · `feedback_dd_methodology_chairman_20251227.md`

## 〇、四条铁律（任何时刻，违反即返工）

1. **数据先进 JSON，格式靠母版克隆，QC 不过不交付** —— 数据与逻辑分离，构建器零硬编码
2. **修改必备份，绝不覆盖原文件** —— 保留终审人加粗/批注/涂黄，重建用新文件名
3. **数据必须有来源，查不到明说+替代方案，绝不编造** —— 无来源的裸数据禁止出现
4. **能力描述基于事实，不夸大、不臆断，建议必须有依据**
5. **给数先验勾稽、矛盾先澄清、不魔改**（客户丙0902⚡）：外部/上级给一个"应该对的数"，先拿它与利润表/已定比率/净利三方勾稽；勾稽不上就向终审人澄清口径来源，**绝不机械按给的数改**，以免上下矛盾连锁（例：252.63亿营业成本与利润表净利16.53、已定毛利率7.21%三方矛盾，先澄清口径再定）。

## 一、动笔前：三要素 + 结构设计

### 1. 确认三要素
| 要素 | 说明 |
|---|---|
| 目标公司 + 素材 | 底稿Excel / 草稿docx / 征信PDF / 认证资料，逐份提取精读 |
| 格式母版 | 同业务线**最新定稿**报告 docx（克隆字体/缩进/行距/表格样式，不靠猜） |
| 授信要素 | 额度 / 账期 / 增信，**以业务最新口径为准**（随时会变，如账期90→120天） |

### 2. 结构贴合企业类型（不是模板套用）
- 贸易/轻资产企业**不硬套制造业模板**：删空话章节（❌"（五）生产设施：无自有生产设施"），改为有实质内容的章节（✅"（五）核心竞争力分析"：供应链整合/物流/风控能力）
- **每个章节必须有实质信息，无实质内容的章节宁删不凑**；章节序号顺延+目录同步

### 3. 章节骨架（6章，可因企业类型精简）
尽调报告意见 → 释义 → 一、项目概况 → 二、行业概况 → 三、公司基本情况 → 四、财务状况 → 五、信用与处罚情况 → 六、总结（负债分析独立成章，见 §二.8）
> ⚡2026-08-13 终审人指令：删除「五、业务风险及风控措施」章节，风险内容并入总结或其他章节，后续章节顺延。

## 二、写作中：内容质量八项标准

### 1. 表述精确化（文字功底）
| 错误 | 正确 | 修正逻辑 |
|---|---|---|
| 预付帐期 | 预付账期 | 错别字 |
| 应收及预付占款 | 应收及预付账款 | 术语标准化 |
| 需具备 | 须具备 | 公文规范用语 |
| 核心团队简介 | 实际控制人简介 | 标题与内容匹配 |
| ...具体信息如下表所示 | ...具体信息如下表所示。 | 标点/句子结构 |

### 2. 风控措辞严谨化（不夸大、不臆断）
- ❌"价格波动敞口未对冲" → ✅"价格通过背靠背进行风险对冲"（准确的业务实际）
- ❌"我司在赊销模式下通过期现套保对冲" → ✅"我司可以通过期现套保对冲"（不夸大我司能力）
- ❌无依据的建议 → 删除（如"建议关注XX是否建立套保机制"）
- 原则：**能力描述基于事实；建议必须有依据**

### 3. 数据来源可溯（每个数据点标注来源）
- "经网络查询"（集团概况开头）
- "经同花顺iFind信用核查"（客商信用）
- "据央行征信报告2026-01-21"（统一社会信用代码）
- "据2026年3月财务报表"（注册资本）
- "数据来源于企业提供的未经审计财务报表"
- 原则：**数据必须能追溯到来源**

### 4. 如实披露信息缺口（绝不假装查到）
- ✅"运营风控组未能获取永荣控股的财务情况，拟通过其控股上市公司永杉锂业（603399.SH）经营及股价做侧面观察"
- ✅"目前尚未获取吴华新个人征信报告，建议要求其提供"
- 原则：**查不到就明说查不到，并给出替代核查方案**

### 5. 客商信用核查（贸易企业尽调核心）
- 用同花顺iFind核查应收/预付**前十大客商**
- 核查维度：欠税公告、严重违法、失信被执行、限制高消费、纳税信用A级
- 原则：**贸易企业风险在上下游，客商信用是尽调重点，必须逐户核查**

### 6. 不重复已知信息
- 同一信息全篇只出现一次，放在最合适的位置（如集团概况直接切入核心，不堆砌发展史细节）
- 正文已有细节（注册地址/征信明细/中登网）不在意见区重复

### 7. 可比公司选择的专业度
- 选**经营模式相近**的同类上市公司（贸易企业→厦门国贸/厦门象屿/建发股份/授信委托方）
- 对比维度：营收/净利/毛利率/净利率/资产负债率/应收与存货周转天数
- **生产型企业与贸易企业分开呈现**：生产型单独列示并注明"业务模式不同，仅供参考"（❌永杉锂业不放进贸易可比表）
- 表格列序：**新日期在左**（2026Q1→2025→2024，勿默认旧→新）

### 8. 负债到期分析章节规范（终审人结构要求）
1. **提级为独立一级章节**：如"七、负债到期情况及现金流压力测试"，不放信用与处罚下面当子章节
2. **信贷明细表7列**：序号/授信机构/开立日期/到期日/借款金额/当前余额/担保方式（五级分类通常可省）
3. **按到期日由近及远排序**（最早到期在最上）
4. **中长期与短期分表**：中长期借款、短期借款、担保交易、授信额度分别列表
5. **现金流压力测试三情景**：基准/悲观/乐观，基于现金流量表+贷款到期测算；**情景变量选业务内生变量**（客户丙0902⚡：回收/加工类企业成本**不随外生商品价**，用营业成本率/毛利率做变量，而非碳酸锂价格；用历史"净利/毛利"结构外推）。**产能分三档**（已投产/在建/规划严格区分；"已投产"才计入利用率分母，如57万吨=已投产30+27，规划30万吨另计）
6. **授信额度原则上不考虑**在压力测试现金流覆盖测算中
7. 表格注释用"备注："（非"注："）；测算结论措辞严谨（"且"非"或"）

### 9. 产业链/参股布局核查 + 来源标注 + 结构化表述（2026-08-12某正极材料客户甲定稿学习⚡）
- **查公司参股公司/产业链上下游布局**：如客户甲参股磷化客户甲构建"磷钛铁锂"（硫酸亚铁铁源→磷酸铁前驱体→碳酸锂），逐家列**股权结构/业务/战略意义**表（可作公司基本情况一节）
- **风险识别延伸到关联布局**：参股/在建项目短期不产生现金流、无法缓解营运资金压力的，列为风险提示项，并标注"实际执行待观察"
- **来源标注强制**：每个事实标来源（"根据公司年报整理""经同花顺iFind""据公司公告"），可追溯
- **在建项目结构化表述**：用①/②编号+资金来源（超募/自筹）+投入金额+完工时间
- **复杂关系表格化**：股权/业务/意义等用表呈现，优于叙述
- **不确定事项审慎标注**："尚在规划中""实际执行情况有待观察"，不夸大

## 三、财务分析（三表 + 比率）

### 1. 财务三表标准列（终审人固定审阅习惯）
- **资产负债表**：项目 | 最新期末 | 占比 | 上期末 | 较上期末变动 | 再上期
  - 占比口径：资产项÷总资产 / 负债项÷总负债 / 权益项÷所有者权益
  - ⚠️ **陷阱**（2026-08-24 某正极材料上市客户乙实证）：
    - **负债和所有者权益总计=100.00%**（不能÷所有者权益，否则算出465.43%的错数）
    - **资产负债率行=—**（不适用占比）
    - **占比四舍五入须与口径一致**：如货币资金 7.39÷19.19=38.51%（勿错填38.49%凑整）
    - **表与正文占比必须一致**（正文说38.51%，表却38.49%=不一致，返工点）
    - **应收占比用原值口径须注明**：坏账准备前总额（如占应收账款总额(原值口径)87.01%），与净额区分
- **利润表/现金流量表**：项目 | 本期 | 上年度 | 变动比例 | 再上期
  - 变动比例=本期÷(上年度÷12×本期月数)−1（同期折算）
- 比率变动用 pct；时点数据（期末现金余额）标"不适用"；亏损收窄/扭亏为盈/由负转正用文字标注
- 三表下方五号字备注说明折算口径

### 2. 财务比率分析
- **放财务状况章节内作为编号小节**（如"（七）财务比率分析"），不单独成章
- 含偿债/盈利/营运三类指标
- **新指标必须附计算口径备注**（如利息保障倍数=（利润总额+财务费用）÷财务费用）
- **应收账款周转天数须与订单结算周期（账期）对比**做匹配性分析

### 3. 数据交叉核对
- 底稿与草稿不一致 → **以原始凭证为准**（征信报告、报表原件），差异在备注说明
- 复杂测算（压力测试敏感性/比率）→ **脚本精确计算验证后再写入**，不手算
- OCR/估算数据标注"仅供参考"

### 4. 比率反向复算（客户丙0902⚡，交付前必跑 `dd_report_consistency.py`）
- **凡写入的比率/增幅/天数，必须用表内底层数反向复算一遍再落**：净利率=净利÷营收、毛利率=（营收−营业成本）÷营收（**默认标准口径**，若用扣税金及附加等异口径必须注释且全文统一）、资产负债率=负债÷资产、同比增幅=（本期−上期）÷上期、周转天数=365÷周转率。
- **口径必标**：周转天数注明"期末余额还是平均余额、含不含应收票据"；已获利息倍数分母≈0（财务费用极小）时警示"指标失真、参考有限"。
- **勾稽必过**：资产=负债+权益、负债=流动+非流动；现金流 经营+投资+筹资=净增减=期末−期初（本期曾抓出 -10-3-10=-23≠-18 的隐藏勾稽错）。
- **小数值科目**（<1亿元）的亿元四舍五入会导致变化率偏差，须备注口径（如 0.99→11.14亿元 复算~1024%，报告显示精确值150%需注明）。

## 四、尽调报告意见区写作（七条 —— 2026-08-24 某正极材料上市客户乙升级：意见落点=风控决断⚡）

> ⚡ 2026-08-24 某正极材料上市客户乙终审人手改意见学习，把「意见区」从"摘要层"升级为"**决断层**"。终审人把我①-⑤措施清单一句话拍板成"客户乙之子公司乙2资信相对较差，不应共用8,000万元额度，应当限额"。
> 意见区是**报告的面子+结论**，类似博爱高/高层前瞻小结，**独立成页**。

0. **★意见落点=风控决断，不是全面总结**（最高原则）：
   - 结尾落一句**可执行决策**，而非①-⑤措施清单。例：识别弱信主体（客户乙之子公司乙2）→"不应共用额度→应当限额"。
   - 这是**资信风险视角**（放账=借钱→识别弱信主体→拆分限额）的落地；呼应"可执行性>收益预期"。
   - **风险做减法**：宁精勿凑，7条→4条。删背景/次要（母公司连亏、应收高企、信息缺口），只留直接决定授信安全的。
   - **结论层剥脂**：删技术细节括号、删数据来源标注（来源在正文，不重复）、删收散长尾——意见只留结论骨架。
   - **措辞克制**：「自我造血弱」→「资金压力较大」（免定性标签）；「注册资本」→「实缴资本」（授信更看重实缴）；「客户」→「下游客商结构」。
   - **标题简化**：【总体评估与风控措施】→【总体评估】，措施内化为决断句。

1. **意见=摘要层，不重复正文**：只放判断性结论+关键数字，细节留正文（三章基本信息表/六章征信表已含的不重复）
2. **小标题语义化+编号化**：【项目需求】拆成"1、额度需求 / 2、账期需求"；"核心团队"→"实际控制人介绍"、"业务模式"→"公司主营业务"
3. **业务口径精确定量化**：「预付账期为1个月」→「预付账期最高不超过30天」；「账期7个工作日」→「赊销账期最高不超过7个工作日」，明确上限约束
4. **精简合并**：同类信息合并（如征信核查渠道合并为"经网络核查及企业征信报告查询"）；资质荣誉一句带过
5. **删除冗余定位句**：删"本授信未设置独立抵押…"等在释义/风险提示已出现的句子
6. **口径变更必须全篇传播**：意见改了账期后，封面标题/授信需求表/额度测算/财务比率匹配性4处全部同步 → **Grep 全篇同口径并同步**

| 项 | 规范 |
|---|---|
| 字体 | 数字/金额/日期 **Times New Roman**；中文/序号 宋体；表头宋体加粗；**汇总行Bold** |

- 圈号序号①-⑳ **用宋体**（构建器 styled_run 已修复：圈号单独run设hAnsi=宋体）

## 六、修改纪律（编辑/迭代时）

1. **上一版本必须全部保存**：改前先完整复制备份（保留原文件），再复制一份作修改副本，输出用新文件名
2. **保留终审人所有格式标注**：加粗、批注、涂黄高亮、手动改动文字，重建时全部保留；可额外加粗自己认为的重点，**绝不删除/改变终审人已有加粗**
3. **修改前先提取完整信息**：读docx同时提取批注（comments.xml）、高亮（run w:highlight）、加粗（run bold），纳入识别清单
4. **识别用户改动**：解包新旧文档diff，**归一化引号实体**（`&#x201C;`）避免误判
5. **手术式编辑优先**：单点修改用Edit/python-docx局部改，不从零重建（防丢格式/批注/颜色）

## 七、质量门禁：三检制 + 4-Gate

```
【第一检 生成前】python -c "import json; json.load(open('content.json'))" → JSON格式验证
【第二检 生成后】python tools\dd_report_qc.py <输出.docx> qc_config.json
                 → Gate1 结构(章节齐全+导航大纲+TOC)
                 → Gate2 格式(对齐/缩进/段前段后/表格)
                 → Gate3 数据(禁用词/关键数字/主体名)
                 → Gate4 内容(风险7类/贷款明细/每章内容量)
                 → exit 0通过 / 1警告评估 / 2=FAIL必须修复重建
【第三检 交付前】Word COM打开 → 更新目录 → 目视：
                 □封面 □目录有页码 □各章标题 □抽查正文缩进/表格字号 □无禁用词残留
```
**门禁：exit code=2（FAIL）禁止交付。** 目录：用标题1样式+outlineLvl（不内嵌TOC域代码），或构建器原生fldChar域+COM更新。

## 九、某正极材料客户甲实战沉淀（2026-08-12，终审人定稿学习⚡）

> 本次某正极材料客户甲尽调报告从生成到终审人定稿全流程沉淀，全部作为方法论标准执行。

### 1. 同业比较多指标（11项标准，同花顺统一口径）
- 对比维度：营业收入/归母净资产/应收账款/存货/应收账款周转天数/存货周转天数/毛利率/归母净利润/净利率/经营性现金流净额/现金比率
- **数据全部取自同花顺iFind统一口径**（客户甲与可比公司同源，避免口径不一致）；归母净资产=权益合计-少数股东权益；净利率=净利润÷营收
- 做2026Q1与2025年度两张表，新日期在前；金额单位亿元；周转天数/现金比率取自同花顺
- 表下备注：数据来源、单位、口径定义

### 2. 现金流压力测试三情景建模（先测算前提说明，再测算表）
- **测算前提说明**：①数据基础（2026Q1现金流/2025折旧/购建支出）②模型口径③价格情景
- **经营现金流**=归母净利润+折旧摊销-营运资金净占用；营运资金随碳酸锂价格双向承压（价涨备货占用增、价跌盈利收窄+存货跌价）→ 让经营现金流压力更大
- **筹资现金流**=有息负债到期续贷测算（短期借款/长期借款/长期应付款），**不含对外担保**（对子公司担保不计入母公司筹资口径）
- **投资现金流**=在建工程后续投入（查公司公告：在建项目完工时间、拟投资额、资金来源，测算2026年需投入金额）
- 测算表列出期初可动用货币资金→经营/投资/筹资→现金净增减→期末可动用货币资金；悲观情景期末为负=资金缺口
- 折旧摊销、购建支出等基础数据从年报提取（折旧计提/购建固定资产支出/在建工程转入）

### 3. 在建项目/产能规范化表述
- 用"根据公司年报整理，主要在建项目有：①/②..."编号；每条注明**资金来源（超募/自筹）+累计投入金额+预计完工时间**；未投产标注"尚在规划中"
- 复杂关系（参股公司股权结构/业务/战略意义）用表格呈现

### 4. 财务表完整性（占比/毛利率）
- 资产负债表**每个项目都要有占比**（资产项÷总资产、负债项÷总负债、权益项÷所有者权益），漏填=返工点（短期借款/应付票据曾漏占比）
- 主营收入构成表**加毛利率列**（按产品分年度），其他业务未披露标"—"
- 应收应付结构**表格化**（项目/金额/说明），不用叙述段

### 5. 派生数据全链重算（价格/口径变动时）
- 碳酸锂价格等关键假设变动时，**全链重算派生数据**（月采购额/在途应收/库存资金占用/负债占比），保证逻辑自洽；"2-3周供货量"类描述须与数据核对（8000万÷15万=533吨≈1.5个工作日，非2-3周）
- 价格取同花顺/主流机构预测值，注明口径

## 十、某正极材料上市客户乙实战沉淀（2026-08-24，多主体共用额度+意见决断⚡）

> 本次某正极材料上市客户乙、客户乙之子公司乙1、客户乙之子公司乙2**共用**应收账款额度8,000万元+15自然日报告，从生成到终审人定稿全流程沉淀，全部作为方法论标准执行。

### 1. 多主体共用授信额度 → 拆分限额（本报告核心新增）
- **授信主体多个（母公司+子公司）共用一笔额度时，逐个主体评估资信，识别弱信主体，不简单共用额度**。
- 某正极材料上市客户乙（龙头，资产负债率65.97%）/ 客户乙之子公司乙1（52.32%稳健）/ 客户乙之子公司乙2（78.51%偏高+未分配利润-6.91亿仍累计亏损，资信相对较差）。
- 结论（终审人决断句）："客户乙之子公司乙2资信相对较差，不应共用8,000万元额度，应当限额"。
- 落地：释义表补"授信主体三"；意见区【项目需求】写明三主体/共用额度/账期/增信；各主体财务**独立展开**；风险提示聚焦最弱主体。

### 2. 意见区=决断层+独立一页（见 §四）
### 3. 财务报表 OCR → 占比列 + 勾稽
- 子公司报表为扫描件OCR：占比列用工具 `dd_financial_table_pct.py` 加（防"边读边插入网格错位 + pct忘×100 + 列偏移"）。
- 勾稽校验：资产=负债+权益、毛利=收入-成本、净利=利润总额-所得税；异常备注"待原件复核"。

### 4. 可比公司数据核验（财务数据接口）
- 财务指标、周转天数均经财务数据接口复核；**营业周期=应收周转天数+存货周转天数**（同业四家可比公司实测区间80~130天）。
- 中报未披露用"—"（行业对比表=未披露保留），区别于"0.00"（无数据）；中报仅已披露者可填，其余注明披露时间。

### 5. 上市公司财务独立章节（抬头=授信主体三）
- 上市公司（某正极材料上市客户乙300769.SZ）为授信主体时，财务独立成章"五、上市公司抬头的财务状况"：资产负债表占比+利润表+现金流量表+重点报表项目分析（应收前五大/受限资金）。
- 应收占比**用原值口径注明**（坏账准备前）；受限资金（其他货币资金=承兑/信用证保证金）单列，实际可动用看现金及等价物。
