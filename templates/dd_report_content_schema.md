# 尽调报告 content.json 编写规范（v3.0）

> 配合 `tools\dd_report_builder.py` 使用。
> 铁律：报告全部内容只写在本JSON里，构建器零硬编码；禁止中文引号（""），需要强调时用【】或《》。

## 顶层结构

```json
{
  "meta": {
    "cover_title1": "上海某贸易客户戊新能源科技有限公司",
    "cover_title2": "应收账款额度5,500万元+账期120天的尽调报告",
    "cover_dept": "新能源事业部运管中心 运营风控组",
    "cover_date": "2026 年 7 月"
  },
  "blocks": [ ... ]
}
```

## blocks 块类型

| 类型t | 字段 | 说明 | 格式来源 |
|-------|------|------|----------|
| cover | — | 封面整页（读meta）+分页 | 母版居中加粗18pt |
| toc | — | 目录页（真实TOC域）+分页 | 居中16pt目录+域代码 |
| h1 | x | 章标题（尽调报告意见/释义/一~七） | 母版标题1样式，outlineLvl 0 |
| h2 | x | 小节标题（一）（二）… | 母版小节格式加粗，outlineLvl 1 |
| br | x | 【项目需求】式加粗导语，无缩进，两端对齐 | 母版【】段 |
| p | x | 正文段，首行缩进2字符，两端对齐，1.5倍行距 | 母版正文段 |
| pni | x | 无缩进正文段（尽调报告意见区专用） | 同br但不加粗 |
| note | x | 备注段（10.5pt五号） | 母版备注段 |
| unit | x | 单位：万元（右对齐） | 母版单位行 |
| tbl | cols, rows, fs, title | 表格；fs=字号（≥4列用9，≤3列用10.5）；title=表格标题（居中加粗，数据表必填） | 三线表+自动对齐 |
| pb | — | 分页符 | — |

## 表格格式（构建器自动执行，无需手写）

- 三线表：顶线sz=12（1.5pt）+底线sz=18（2.25pt）大黑粗线、内部hair细线sz=4、无左右边线
- 对齐自动判定：数字靠右、文字靠左、符号/日期/序号居中、表头居中加粗
- 表格整体水平居中；表头跨页重复；单元格垂直居中

## 财务三表标准列（终审人固定审阅习惯，必须默认执行）

**资产负债表**：`项目 | 最新期末 | 占比 | 上期末 | 较上期末变动 | 再上期`
- 占比口径：资产项目÷资产总计、负债项目÷负债合计、权益项目÷所有者权益
- 权益由负转正/亏损收窄等用文字标注（如"由负转正"、"亏损收窄25.79%"）；资产负债率行占比填"—"、变动填pct

**利润表/现金流量表**：`项目 | 本期 | 上年度 | 变动比例 | 再上期`
- 变动比例 = 本期发生额 ÷ (上年度发生额/12×本期月数) - 1（同期折算比较）
- 比率类变动用pct（如"6.01pct"）；时点数据（期末现金余额）填"不适用"
- 净额为负的比较用文字（"净流出收窄33.35%"、"扭亏为盈"、"由正转负"）
- **三表下方必须加五号字note块说明口径**，示例：
  `备注：①变动比例为2026年1-5月发生额与2025年度同期折算数（2025年度发生额/12×5）的比较；②毛利率变动以百分点（pct）列示。`

## 章节骨架（7章，QC强制）

1. 尽调报告意见（【项目需求】【基本面】【重点风险提示】【总体评估与风控措施】，此区一律用pni/br）
2. 释义（3列表：简称|指|全称）
3. 一、项目概况（项目需求/需求原因及额度测算/历史合作/走访记录/原授信盯办）
4. 二、行业概况（行业背景/行业门槛）
5. 三、公司基本情况（简介+信息表/资质认证+认证表/核心团队/生产设施/技术工艺）
6. 四、财务状况（重要提示/资产负债表/利润表/现金流量表/母公司摘要/应收应付结构/综合评价，报表一律tbl呈现）
7. 五、业务风险及风控措施（风险表必须7类：市场/经营/技术/资金/回款/物流/合规，列：风险类别|风险描述|风控措施）
8. 六、信用与处罚情况（征信概述/中长期借款表/短期借款表/授信额度表/实控人及关联主体/到期压力）
9. 七、总结（亮点/风险/结论/授信建议前置条件）

## qc_config.json（项目级QC配置）

```json
{
  "forbidden": ["母版公司名", "其他项目残留词"],
  "required_subject": "授信主体全称关键词",
  "key_checks": [["5,500万元", "授信额度"], ["120天", "账期"]]
}
```

## 数据纪律

- 数字一律半角+千分位（34,057.12），与底稿原始凭证核对
- 底稿与草稿不一致时以原始凭证（征信报告、审计/未审报表原件）为准，并在备注说明
- 估算值必须标注来源（如"年化约42,000万元"、"OCR识别仅供参考"）
